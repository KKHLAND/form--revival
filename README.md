# 양식 되살리기

편집이 막힌 양식(PDF, 스캔본·사진, 잠긴 hwpx)을 올리면 표와 칸을 원본 배치대로 다시 짜서, 한글에서 바로 고칠 수 있는 **hwpx**로 내려받게 해 주는 단일 HTML 앱입니다. 서버 없이 브라우저 안에서 동작합니다.

| 올린 파일 | 처리 방식 |
|---|---|
| 글자가 있는 PDF | **좌표 복원** — 선·글자 좌표로 표를 재구성 (셀 병합, 선 굵기, 점선·이중선, 대각선, 배경색, 글자 크기·굵기·색·자간, 줄 간격). AI 불필요 |
| 스캔 PDF · 사진 | **AI 인식** — 페이지 이미지를 Gemini(API 키) 또는 Claude(claude.ai 안에서)가 읽어 JSON으로 돌려주면 같은 방식으로 조판 |
| 잠긴 hwpx | 셀 보호·개체 잠금 속성만 풀고 서식은 그대로 둠 |
| 배포용 hwpx · hwp | 암호화되어 직접 읽지 않음 → 한글에서 인쇄 → PDF로 저장 후 올리도록 안내 |

## 폴더 구조

```
index.html            ← 배포용 완성본 (build.py가 만듦. 직접 고치지 마세요)
build.py              ← src/ 조각을 합쳐 index.html 생성
src/
  app.html            ← 화면(HTML·CSS)과 화면 동작 스크립트
  engine.js           ← 변환 엔진: PDF 추출, 표 재구성, AI 결과 변환, hwpx 생성, 잠금 해제
  font-metrics.json   ← 한글 프로그램 글꼴 폭 표(함초롬돋움·바탕, 맑은 고딕, 굴림 등)
  skeleton.hwpx       ← hwpx 골격(빈 문서). 서식·본문은 엔진이 채움
```

## 수정하는 방법

1. `src/` 안의 파일을 고칩니다.
2. `python3 build.py` 를 실행해 `index.html` 을 다시 만듭니다.
3. `index.html` 과 `src/` 를 함께 커밋합니다.

`python3 build.py --check` 는 `index.html` 이 `src/` 와 맞는지만 확인합니다.

## 엔진 메모

- **단위**: 레이아웃은 pt(좌상단 원점), hwpx는 HWPUNIT(1pt = 100).
- **PDF 라이브러리**: pdf.js 3.11.174 (cdnjs). 워커 스크립트를 일반 `<script>`로 불러 메인 스레드에서 돌립니다(아티팩트 CSP 대응).
- **줄바꿈 방지**: 원본의 한 줄은 hwpx에서도 한 문단입니다. `font-metrics.json`의 한글 배치 규칙(4 HWPUNIT 단위, 빈칸 = em/2)으로 폭을 계산해 원본 줄 폭에 맞는 자간을 넣고, 칸 폭을 넘지 않게 줄이며, 문단은 "한 줄로 입력"(`lineWrap="SQUEEZE"`)으로 둡니다.
- **점선**: 한글이 PDF로 내보낸 점선은 아주 짧은 선 조각 수십 개입니다. 조각끼리만 이어 붙여 `DOT`/`DASH` 테두리로 판정합니다.
- **글자색**: pdf.js 글자 정보에 색이 없어 렌더링한 페이지 픽셀에서 읽고 한글 기본 색상표로 맞춥니다.
- **AI 키**: Gemini 키는 `AQ.`(새 형식)·`AIza`(예전 형식) 모두 받습니다. 이 브라우저에 기억하기를 켠 경우에만 localStorage에 저장합니다.
